## ✦ Features

<div align="center">

| | Feature | What it does |
|:---:|---|---|
| 🐾 | Virtual crypto pet | Raise a digital pet in a cage with canvas-based animation |
| ⚠️ | Honeypot detector | Flashes "HONEYPOT DETECTED" alerts for comedic effect |
| 🔗 | Wallet connect | Connect your Base wallet to interact with the pet |
| 💰 | Tip support | Tip the creator in USDC on Base Mainnet |
| 📱 | Farcaster native | Runs inside Warpcast / Base app as a mini app |

</div>

## ✦ Download & Run

**Step 1** .... Clone the repo

```bash
git clone https://github.com/0xnurrabby/My-little-Rugpull
cd My-little-Rugpull
```

**Step 2** .... Serve the files

```bash
start index.html

# Or use a local server
npx serve .
# Open http://localhost:3000
```

**Step 3** .... Connect wallet and interact with the pet

---

## ✦ Setup

```
1. Clone the repo
2. Open index.html in a browser
3. For wallet connect and on-chain features:
   open inside Warpcast or Base app (Farcaster client required)
4. To deploy: push to Vercel
   Vercel serves static files directly, no build step needed
```

## ✦ Project Structure

